About This Dashboard

The Hunger Index is a real-time food insecurity tracking dashboard built for academic research and humanitarian data visualization. It aggregates data from the world's leading open food security monitoring systems into a single, unified interface.

IPC Phase Classification

The IPC scale runs from Phase 1 (Minimal) to Phase 5 (Famine/Catastrophe). Phases 3 and above indicate acute food insecurity requiring humanitarian response.
